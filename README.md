## Sobre o projeto

Este é um sistema de gestão de uma biblioteca universitária que visa atender às demandas dos alunos e funcionários operantes do sistema. Durante este processo ele engloba a perspectiva do usuário do sistema como um aluno, o qual consegue buscar um livro, solicitar a reserva deste, verificar a data de devolução, entre outras funções, e também como um bibliotecário, em que ele obtém um controle dos exemplares atuais no local e dos usuários atualmente cadastrados no sistema, podendo adicionar, remover ou verificar informações desejadas.

## Como instalar

_Passo a Passo utilizando o Git Bash_

1. Clone o repositório através do comando:
   `git clone https://github.com/pds2-dcc-ufmg/2026-2-METATURMA-grupo11.git`

2. Entre na pasta com o comando:
   `cd 2026-2-METATURMA-grupo11`

3. Compile o projeto com o comando:
   `make`

4. Execute o programa com:
   `.build/main`
